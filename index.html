1. Установка
Скачай APK и установи.
1. Установить приложение (APK)
  1. Открой репозиторий nexus_ai_control → вкладка Actions.
  2. Выбери последнюю сборку Build APK → внизу блок Artifacts → скачай nexus-ai-control-apk.
  3. Распакуй архив, скинь app-debug.apk на телефон.
  4. Открой файл → разреши «Установка из неизвестных источников» → Установить.
Без APK тоже работает — открой сайт в Chrome → меню → «Установить приложение». Но фонарик, громкость, захват экрана и тапы будут недоступны: браузер их запрещает.
2. Добавить ИИ
Вкладка 🤖 ИИ → + Добавить ИИ. Заполни:
  1. Название — как хочешь, например «Мой Штаб».
  2. Base URL — адрес без /chat/completions: https://api.openai.com/v1, https://api.deepseek.com/v1, https://openrouter.ai/api/v1.
  3. Модель — gpt-4o-mini, deepseek-chat, llama-3.3-70b-versatile.
  4. API-ключ — вставь свой. Хранится только в памяти телефона, в репозиторий не уходит.
Жми Проверить — если связь есть, покажет число моделей. Зелёная точка = ИИ отвечает, красная = ошибка (URL, ключ или CORS).
3. Общаться в чате
Вкладка 💬 Чат. Сверху чипсы — переключение между ИИ, у каждого своя история. Пиши в поле внизу, Enter — отправить, Shift+Enter — новая строка. Поддерживается markdown и блоки кода.
3.1 Голосовое общение с ИИ
Говорить с ИИ: вкладка 💬 Чат → кнопка 🎤 слева от поля ввода → разреши доступ к микрофону → говори. Распознанный текст появится в поле, а при включённом тумблере «Отправлять сразу после речи» уйдёт в чат сам.
Слушать ответы: тумблер «Озвучивать ответ» — каждый ответ ИИ читается вслух (русский голос).
Голосовые команды телефону: вкладка 📱 Телефон → Слушать. Говори команды: фонарик, фонарик выключи, громкость 60, громче, тише, экран включи, скриншот, запись, назад, домой, недавние, вибрация, батарея, открой youtube.com, позвони 112, спроси у ИИ погода в Москве, стоп. Если команда не распознана — фраза просто уйдёт в чат к ИИ.
Микрофон: в APK работает нативный распознаватель Android (точнее и без интернета-задержек), в браузере — встроенный движок Chrome. Разрешение RECORD_AUDIO спрашивается один раз.
3.2 Навигатор — просто скажи в чате
Никаких карточек и кнопок. Открой 💬 Чат и напиши или скажи голосом:
Составь маршрут до Ленина 15, Москва
Как доехать до аэропорт Шереметьево
Проложи путь до Красная площадь · Довези меня до Тверская 7
Приложение само понимает, что нужен навигатор, вытаскивает адрес и открывает установленный навигатор телефона — Яндекс.Навигатор, 2ГИС или Google Maps — с уже построенным маршрутом.
Ещё понимает: где я — откроет карту с твоим местоположением, и маршрут домой — один раз спросит адрес дома и запомнит его.
Нужен интернет и включённая геолокация. Удалённо: команда моста nav со значением-адресом.
3.3 Живой диалог — говори без кнопок
Вкладка 💬 Чат → кнопка 🔁 Диалог в голосовой полосе сверху.
  1. Нажми 🔁 Диалог — микрофон включается и слушает постоянно, кнопку больше жать не надо.
  2. Говори фразу. Как только замолчал (~1,5 сек тишины) — фраза сама уходит в чат к активному ИИ.
  3. Ответ приходит в чат и озвучивается голосом, после чего микрофон снова слушает — и так по кругу, пока не выключишь.
  4. Выключить: кнопка ⏹ Стоп или просто скажи «стоп» / «хватит» / «замолчи».
Работают и команды телефону прямо в живом диалоге: «фонарик», «громкость 60», «навигатор Ленина 15», «скриншот».
Пока ИИ говорит, микрофон на паузе — чтобы не слышать сам себя.
В браузере живой диалог тоже работает (движок Chrome), но в APK точнее и стабильнее.
4. Управлять телефоном
Вкладка 📱 Телефон: фонарик, вибрация, громкость, статус сети, батарея, буфер обмена, звонок, карты, камера.
Фонарик и громкость работают только в APK — там их выполняет нативный модуль NexusNative через вспышку камеры и системный аудиопоток. В браузере кнопка честно скажет, что нужен APK.
5. Экран телефона и тап-управление
Вкладка 🖥️ Экран.
  1. Нажми Запустить → в окне Android подтверди «Начать запись».
  2. Картинка телефона появится в приложении. Настрой качество JPEG и FPS (1–10).
  3. Пауза — заморозить, Кадр — одиночный снимок, Сохранить кадр — в память телефона.
  4. Для тапов: Включить службу → Настройки → Специальные возможности → Nexus Control → включить. Потом тапай по картинке — нажатие уйдёт в эту точку телефона. Есть свайпы и клавиши Назад / Домой / Недавние.
Root не нужен, но без службы доступности тапы Android не разрешит.
6. Трансляция на Штаб и запись видео
Трансляция: вставь URL приёма (например https://ntfy.sh/твой-топик), задай интервал и жми Начать трансляцию. Кадры уходят POST-ом в JSON {device, w, h, image, ts} — я вижу твой экран со своей стороны.
Запись видео: кнопка Записать пишет кадры трансляции в WebM, таймер сверху. Сохранить видео — файл в память телефона. Держи захват экрана включённым.
7. Мост — я управляю твоим телефоном
Вкладка 🛰️ Мост. Я пишу команды в файл bridge/commands.json, приложение их забирает и выполняет.
  1. Вставь URL канала команд (raw-ссылка на commands.json или свой сервер).
  2. Хочешь отчёты — впиши webhook, туда полетит результат каждой команды.
  3. Жми Подключить — опрос пойдёт по таймеру. Забрать сейчас — разовая проверка.
Команды: torch, volume, toast, notify, vibrate, speak, listen, open, clip, ask, status, nav, whereami, screen, screenshot, stream, record, tap, swipe, key.
8. Если что-то не работает
ИИ не отвечает — проверь Base URL (без /chat/completions), ключ и что у провайдера открыт CORS.
Фонарик/громкость молчат — ты в браузере, нужен APK.
Экран чёрный — не подтвердил запись или приложение ушло в фон; запусти захват заново.
Тапы не работают — служба «Nexus Control» выключена в специальных возможностях.
Мост не забирает команды — проверь URL и что seq в файле больше, чем в приложении.

# Wlupidol AI Control

ИИ-хаб и пульт управления телефоном. Работает как веб-приложение (PWA) и как настоящий **APK** для Android.

**Веб-версия:** https://alexey17001700-coder.github.io/nexus_ai_control/

---

## Что внутри

| Вкладка | Возможности |
|---|---|
| 🤖 **ИИ** | Добавить / изменить / удалить любого ИИ с OpenAI-совместимым API. Пресеты: OpenAI, OpenRouter, DeepSeek, Groq, локальный Штаб, свой сервер. Кнопка «Проверить» дёргает `/models`. |
| 💬 **Чат** | Переключение между ИИ чипсами, отдельная история на каждого, markdown и код. |
| 📱 **Телефон** | Фонарик, громкость, вибрация, батарея, сеть, буфер обмена, звонок, карты, камера. |
| 🛰️ **Мост** | Канал удалённых команд. Архитектор пишет команды в `bridge/commands.json` — приложение забирает их и выполняет на телефоне. |

Ключи ИИ хранятся **только в памяти телефона** (localStorage), в репозиторий не пишутся.

## Получить APK

1. Репозиторий → вкладка **Actions** → **Build APK** → **Run workflow**
2. Дождаться зелёной галочки (~5 минут)
3. Внизу страницы запуска → **Artifacts** → `nexus-ai-control-apk` → внутри `app-debug.apk`

Сборка запускается автоматически при каждом push в `main`.

Скинуть `.apk` на телефон → «Установка из неизвестных источников» → готово.

## Нативный модуль NexusNative

Собирается автоматически при сборке APK: workflow копирует `native/android/*.java.txt` в сгенерированный Android-проект и прописывает разрешения в манифест.

Доступен из JS как `Capacitor.Plugins.NexusNative`:

| Метод | Аргументы | Что делает |
|---|---|---|
| `torch` | `{on: true/false}` | Вспышка камеры |
| `volume` | `{level: 0..100}` | Громкость медиа |
| `toast` | `{text}` | Системный тост Android |
| `notify` | `{title, body}` | Уведомление в шторке |
| `info` | — | Модель, версия Android, состояние фонарика |

## Мост: удалённое управление

Приложение опрашивает JSON-файл и выполняет новые команды.

**Формат `bridge/commands.json`:**

```json
{
  "seq": 1,
  "cmds": [
    { "id": "c1", "action": "torch",  "value": "on" },
    { "id": "c2", "action": "toast",  "value": "Привет, Босс" },
    { "id": "c3", "action": "speak",  "value": "Проверка связи" },
    { "id": "c4", "action": "ask",    "value": "Какая сегодня погода?" }
  ]
}
```

`seq` увеличивается — приложение выполняет только команды с новым `seq` и запоминает его.

**Доступные действия:**

| action | value | Результат |
|---|---|---|
| `torch` | `on` / `off` | Фонарик (APK) |
| `volume` | `0..100` | Громкость медиа (APK) |
| `toast` | текст | Тост на экране |
| `notify` | текст (+ `title`) | Уведомление в шторке |
| `vibrate` | — | Вибрация |
| `speak` | текст | Озвучить голосом |
| `open` | URL | Открыть ссылку |
| `clip` | текст | Положить в буфер обмена |
| `ask` | вопрос | Спросить активный ИИ и озвучить ответ |
| `status` | — | Батарея и сеть |

**Отчёты:** если в настройках моста указан webhook (например `https://ntfy.sh/мой-топик`), после каждой команды туда уходит POST с результатом.

# Nexus AI Control

Мобильное приложение: добавляешь любые ИИ (OpenAI-совместимый API), общаешься с ними, управляешь телефоном.

## Что уже есть (ЭТАП 1)
- Список ИИ-провайдеров: добавить / изменить / удалить.
- Пресеты: OpenAI, OpenRouter, DeepSeek, Groq, локальный Штаб, свой сервер.
- Проверка связи (`GET /models`) — зелёная/красная точка у каждого ИИ.
- Чат с выбранным ИИ, история отдельно для каждого, markdown-код.
- Панель команд телефона: фонарик, вибрация, батарея, сеть, буфер, звонок, карты, камера.
- Ключи хранятся только в localStorage телефона, в репозиторий не попадают.

## Установка на телефон (без APK)
Открой ссылку GitHub Pages → меню Chrome → «Установить приложение» / «Добавить на главный экран».

## APK
ЭТАП 2 — сборка через GitHub Actions (Capacitor), готовый `.apk` появится в разделе **Actions → Artifacts**.

## CORS
Если ИИ не отвечает из браузера — сервер должен разрешать CORS. Для локального Ollama:
`OLLAMA_ORIGINS=* ollama serve`

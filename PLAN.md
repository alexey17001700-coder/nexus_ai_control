# Nexus AI Control — ПЛАН

## 1. ЖИВОЙ РЕЖИМ (кнопка 🎤)
- Нажал кнопку → слушает всё время, пока не выключишь.
- Выключил кнопку → выключено. Никакого фона, никаких слов-триггеров.
- Кнопка включена → **всё голосом**: ИИ отвечает голосом, переспрашивает голосом, если не понял.
- Кнопка выключена → обычный текстовый чат.
- **Если Босс молчит:** тихо слушает + напоминает, что слушает (тихий индикатор/пик). Само не выключается.
- **Экран:** включил живой режим → экран горит 30 минут. Через 30 минут экран гаснет, **но микрофон продолжает слушать** — живой режим идёт дальше с выключенным экраном. Выключил кнопку → всё встало.
- **Озвучка:** ИИ читает ответ целиком, как есть (включая длинные). Сказал «хватит» — замолкает немедленно, слушание продолжается.

## 2. УПРАВЛЕНИЕ ТЕЛЕФОНОМ
Пока только два действия:
1. **Навигатор** — маршрут.
2. **Поисковик** — «найди…», «загугли…», «поищи…», «что такое…».

Правила:
- **Назвал приложение** («открой Яндекс / Google / Chrome / …») → открывается именно оно.
- **Не назвал** → поисковик по умолчанию автоматически, без диалога «чем открыть?».
- **Приложения нет на телефоне** → ИИ говорит: «такого приложения у вас на телефоне нет».
- Работает и текстом, и голосом в живом режиме.

Всё остальное (звонки, сообщения, будильник, музыка и т.д.) — отложено, расширяем только по слову Босса.

## 3. ЗАЩИТА (замки)
- **Навигатор и поисковик — без отдельного доступа.** Никаких разрешений, PIN, подтверждений.
- **Замки включаются ТОЛЬКО при режиме тапов по экрану** (когда ИИ управляет экраном телефона и хочет открыть какое-то приложение).
- **Разрешение спрашивается один раз при входе в приложение.** Подтвердил вход (палец/голос) → дальше в этом приложении свободно, пока режим тапов включён. На каждый тап не спрашиваем.
- **«Мёртвая рука» — 15 минут.** Нет касаний 15 минут → режим тапов гаснет сам, разрешения снимаются.
- Пока опасных действий нет — замки не мешают обычной работе.

## 4. НАДЁЖНОСТЬ
- **Фоновый режим:** 30 минут экран горит, дальше экран гаснет — микрофон продолжает работать.
- **Автозапуск:** НЕ нужен. Приложение запускается руками.
- **Оффлайн:** нет интернета → навигатор и поиск не работают. Сообщаем «нет сети» и ждём.
